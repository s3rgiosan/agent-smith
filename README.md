# Agent Smith

![Agent Smith](agent-smith.gif)

Tools, scripts, skills and agents for agent-driven development: the small things that make working with Claude Code faster, clearer and a little more fun.

Each folder has its own README with the details.

## `scripts/`

Standalone shell scripts for the chores that pile up around agent-driven work, such as rewriting an Obsidian vault's paths after a folder move.

## `claude/`

Everything that customizes Claude Code: slash commands, skills, a status line, installers, a project manager and spinner verb themes.
